Iowa Senate File 481 gives the state power to withdraw funding from cities that go against state legislation.[^1] It was signed into effect on April 10th, 2018. It was originally written to prevent cities from protecting immigrants from state and federal authorities, but has also been cited in efforts to prevent cities from protecting transgendered people from danger as well.

[^1]: https://www.legis.iowa.gov/legislation/BillBook?ga=87&ba=sf481
