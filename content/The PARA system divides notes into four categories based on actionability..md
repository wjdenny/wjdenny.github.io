The PARA system divides notes into four categories based on actionability[^1]. A note that has a specific end date and goal to it is considered a *project.* A note that has no goal, but a status to maintain, it is considered an *area.* *Resources* are the reference materials not tied to one specific project or area. *Archives* are items that are no longer actively used.
